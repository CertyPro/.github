# .github

Organisation-wide defaults for [CertyPro](https://github.com/CertyPro).

- `profile/README.md` - the public profile shown on the organisation page.
- `SECURITY.md`, `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `PULL_REQUEST_TEMPLATE.md`
  - defaults applied to any repository that does not provide its own.

Learn more at **https://certy.pro**.
